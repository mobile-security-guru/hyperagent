# Compliance questions

Work through these in order. Each answer becomes one or more rows in the actions table.

1. **Policy statements.** Extract every statement in the mobile, BYOD, acceptable use, and access control policies that involves a phone. One row per statement.
2. **Execution records.** For each statement: which record shows it was carried out during the audit period, and which system holds that record?
3. **Access reviews.** Do access reviews cover access from phones to sensitive systems? Which reviewer signed off, and where is the sign-off?
4. **Last audit.** Which evidence requests from the last audit were answered with policy text, a screenshot, or a description in place of a record? Mark each as UNKNOWN until a record is found.
5. **Offboarding.** Which record shows phone access and phone-based factors were removed when each person left during the period?
6. **Exceptions.** For each BYOD or MFA exception: who approved it, when does it expire, and where is that written down?
