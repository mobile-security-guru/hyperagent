# Compliance inputs

Ask the user for these. Any missing file turns the questions it serves into UNKNOWN.

| File | Where it usually comes from | Serves questions |
|---|---|---|
| Mobile, BYOD, acceptable use, and access control policies | Your policy library | 1, 2 |
| Most recent access review results | Your identity governance tool's review export | 3 |
| Last audit's evidence request list and responses | Your audit or GRC tool (names can be removed first) | 4 |
| Offboarding checklist and a sample of offboarding tickets | HR or IT | 5 |
| Exceptions register | Your GRC tool or security team | 6 |

Fields to skip: personal contact details, device location, message content. The method does not need them.
